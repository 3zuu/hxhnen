📋 Quick Guideدليل سريع

1. Hero → Edit title, subtitle, badge, scroll hint

١. الهيرو ← عدّل العنوان والوصف والشارة

2. Sections → Edit all section headings and descriptions

٢. الأقسام ← عدّل عناوين جميع الأقسام وأوصافها

3. Nen Types → Edit type names, descriptions, water test, personality, characters + upload character images

٣. أنواع النين ← عدّل الأسماء والأوصاف واختبار الماء والشخصية والشخصيات + ارفع صور الشخصيات

4. Groups & Chars → Upload/change character images for all groups (Zoldyck, Troupe, Zodiacs, etc.)

٤. المجموعات ← ارفع/غيّر صور الشخصيات لجميع المجموعات

5. Quiz → Add/edit questions (8 random shown per session)

٥. الاختبار ← أضف/عدّل الأسئلة (8 عشوائية في كل جلسة)

6. Footer → Add your social/portfolio links

٦. الفوتر ← أضف روابط سوشيال/بورتفوليو

7. Click 💾 Save All → Download nen-config.js → upload to GitHub → Vercel auto-deploys

٧. اضغط 💾 حفظ الكل ← نزّل nen-config.js ← ارفعه على GitHub ← Vercel يحدّث تلقائياً
