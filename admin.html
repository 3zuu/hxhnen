📋 Quick Guide

1. Hero Tab → Edit page title, subtitle, badge text

2. Sections Tab → Edit section headings and descriptions

3. Nen Types Tab → Edit names, descriptions, character abilities for each type

4. Footer Tab → Add/remove your social links, portfolio, etc.

5. Settings Tab → Change admin password, site colors

6. Click 💾 SAVE ALL → Download updated index.html to replace on your host

🚀 Deployment Guide

GitHub + Vercel:

1. Create a GitHub repo (e.g. nen-world)

2. Upload both index.html and admin.html

3. Go to vercel.com → Import your repo

4. Deploy — your site will be live in seconds!

Security:

• admin.html is only accessible if someone knows the URL

• Password is checked client-side — ideal for personal projects

• For higher security: add Vercel Password Protection (Pro plan) or rename admin.html
